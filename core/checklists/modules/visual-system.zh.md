# Visual System 高风险模块

用于补强 `ui-audit.zh.md` 中视觉体系的检查，重点发现 spacing、typography、color、radius、border、shadow 和装饰语言不成系统的问题。

## 使用时机

- 页面看起来像多个模板拼接，或者用户反馈“不精致”“风格乱”“AI 味重”。
- 同屏出现多套圆角、边框、阴影、按钮风格、卡片密度、图标线宽或强调色。
- fix/polish 需要保留主题，但提高成熟度和一致性。

## 必查点

- 层级系统：H1/H2/body/caption/button 的字号、字重、行高和间距是否形成少量稳定层级。
- 色彩用途：主色、强调色、状态色、链接色、数据高亮是否有明确职责，避免全屏同色或高饱和滥用。
- 容器语言：card、panel、modal、popover、table、form control 的 radius、border、shadow 是否来自同一尺度。
- 空间节奏：页面容器宽度、section spacing、卡片内边距、grid gap 和按钮间距是否成比例；间距应表达内容关系，而不是平均放大或压缩所有空白。
- 装饰克制：渐变、玻璃拟态、发光、背景图、纹理、mask、filter、blend mode 是否服务信息，而不是掩盖内容不足。
- 图标和媒体：图标线宽、尺寸、颜色继承、插图/mockup/截图比例是否和组件体系一致。
- 主题保留：修复时应收敛现有方向，不在未授权时换成另一种审美。

### 空间关系模型

- 元素级：图标与文字、标题与说明、label 与控件、按钮文字与图标等紧密关系应被识别为一个整体；不要用过大的 gap 拆散，也不要拥挤到影响辨认和点击。
- 分组级：卡片内部、表单组、筛选区、按钮组和工具栏应满足“组内间距小于组间间距”；padding 和占用面积要匹配信息量与操作密度。
- 区块级：hero、内容区、列表、FAQ、CTA 和 footer 之间应有清楚停顿，但不能通过统一的大 section padding 把相关路径拉断、把核心内容推到首屏之外。
- 相对关系优先于固定数值：优先判断元素级、分组级、区块级的疏密层次是否成立，再判断具体 spacing token；不要把 `8/16/32px` 等数值机械应用到所有页面类型。

### 留白判断

- 有效留白：强化分组、层级、阅读停顿或主操作优先级。
- 无效留白：没有表达内容关系，只造成空洞、下沉、扫描路径断裂或信息密度失衡。
- 内容空洞：容器面积明显大于真实信息量时，先判断模块职责、内容结构或视觉对象是否不足；不要只缩小或放大 spacing 来掩盖根因。

## 分级提示

- `Critical`：视觉体系问题直接导致核心内容不可读、主操作不可辨认，或主题/内容关系混乱到用户无法理解页面。
- `Major`：同屏 token、组件、色彩职责或装饰语言明显分裂，或多个核心模块反复出现局部拥挤、粘连和分组不清，降低专业感、扫描效率、可信度或操作判断。
- `Minor`：局部 spacing、radius、shadow、图标线宽或动效节奏不够统一，但不破坏整体系统。

## 浏览器验证

- 先看页面级节奏，再进入导航、筛选、表单、卡片、表格工具栏或 CTA 等核心模块，最后检查标题/说明、label/控件/帮助文本、图标/文字和按钮组等组件内部关系。
- Standard 至少抽查一个核心功能模块；Focused 覆盖主要模块并抽查重复组件；Deep 在一个核心视口完成页面级、模块级、组件内部三级检查。
- 在桌面和移动端检查字号、间距、卡片密度、按钮层级是否仍成立；代码中的 spacing 数值只用于解释浏览器或截图中已经可见的拥挤/空洞。
- 对 hover/focus/active 状态检查是否沿用同一色彩和边框体系。

## 典型问题信号

- 主按钮是 pill，卡片是大圆角，输入框是小圆角，弹窗又是另一套圆角。
- 所有可强调元素都用同一个高饱和色，用户无法判断主操作。
- 每个 section 都有不同背景、卡片、图标和装饰手法，像拼贴模板。
- 阴影、玻璃拟态或发光太重，导致界面廉价或阅读疲劳。
- 所有元素使用接近的间距，组内、组间和 section 之间没有可辨认的疏密层次。
- 为了制造呼吸感统一放大 padding 和 gap，导致相关内容失去关联、首屏空洞或核心操作下沉。
- 修复后虽然问题少了，但主题被换掉，前后像两个产品。

## 修复边界

- 不要用“更高级”作为理由改主题；必须说明对清晰度、一致性、可用性或真实感的影响。
- 先确认内容分组和页面构图，再统一 spacing token 和组件关系，最后处理局部 polish。
- 视觉修复应保留业务内容和产品语气，不用装饰替代真实信息结构。
